Instalação do GTM e do evento de lead nas páginas do Black Pass

Para quem cuida das páginas no Lovable: é só colar um prompt e publicar. Com isso o Pixel do Meta e o GA4 passam a medir as visitas e os cadastros do Black — hoje as páginas não têm rastreamento.

O que você precisa fazer

3 passos, uns 5 minutos

Páginas: november.institutofernandaben.com.br e /lista-prioritaria · Container GTM: GTM-KX2QL6XG

1

Copie o prompt abaixo e cole no chat do projeto no Lovable

Ele instala o GTM e ajusta o evento de cadastro. Não mexe em layout, textos, formulário nem checkout.

Preciso instalar o Google Tag Manager e ajustar os eventos do dataLayer neste projeto. NÃO altere layout, textos, estilos nem o fluxo do formulário e do checkout. 1) Instalar o GTM (ID GTM-KX2QL6XG) em TODAS as rotas, incluindo "/" e "/lista-prioritaria": - Coloque o script abaixo o mais alto possível no <head> do documento raiz (no TanStack Start, no head() da rota raiz, ex.: src/routes/__root.tsx; se o projeto tiver index.html, no <head> dele). - Coloque o <noscript> logo depois da abertura do <body> no documento raiz. - O GTM deve carregar UMA única vez (sem duplicar na navegação entre rotas) e não pode existir outro container GTM no projeto. Script do <head>: <!-- Google Tag Manager --> <script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start': new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0], j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src= 'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f); })(window,document,'script','dataLayer','GTM-KX2QL6XG');</script> <!-- End Google Tag Manager --> Trecho do <body>: <!-- Google Tag Manager (noscript) --> <noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-KX2QL6XG" height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript> <!-- End Google Tag Manager (noscript) --> 2) Evento de lead: no dataLayer.push do evento 'blackpass_lead_success' (que já é disparado quando o cadastro é confirmado com sucesso pelo servidor), inclua estes campos, mantendo os que já existem: - event_id: string única por cadastro, gerada uma vez no envio com crypto.randomUUID() - email: e-mail digitado, em minúsculas e sem espaços - name: nome digitado, sem espaços nas pontas - phone: telefone no formato E.164 ('+' + DDI + DDD + número, só dígitos), ex.: +5511999998888 Garanta window.dataLayer = window.dataLayer || [] antes de qualquer push. 3) Na rota /lista-prioritaria, dispare window.dataLayer.push({ event: 'blackpass_page_view' }) ao carregar a página, do mesmo jeito que já acontece na raiz. 4) Não envie e-mail, nome ou telefone em nenhum outro evento além do 'blackpass_lead_success'. No final, me mostre a lista de arquivos alterados e um resumo do que mudou.

GTM no <head> do layout raiz

No TanStack Start, no head() da rota raiz (ex.: src/routes/__root.tsx); se houver index.html, no <head> dele. Um container só, carregado uma única vez.

<!-- Google Tag Manager --> <script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start': new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0], j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src= 'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f); })(window,document,'script','dataLayer','GTM-KX2QL6XG');</script> <!-- End Google Tag Manager -->
B

GTM logo depois da abertura do <body>

<!-- Google Tag Manager (noscript) --> <noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-KX2QL6XG" height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript> <!-- End Google Tag Manager (noscript) -->
C

Campos no evento blackpass_lead_success

Só depois que o servidor confirmar o cadastro. Dados pessoais vão apenas neste evento.

// Só depois que o servidor confirmar o cadastro com sucesso const eventId = crypto.randomUUID(); // gerar UMA vez por cadastro window.dataLayer = window.dataLayer || []; window.dataLayer.push({ event: 'blackpass_lead_success', event_id: eventId, // único por cadastro email: email.trim().toLowerCase(), // e-mail digitado name: nome.trim(), // nome digitado phone: '+' + (ddi + telefone).replace(/\D/g, '') // ex.: +5511999998888 // manter aqui os demais campos que o evento já envia hoje });
D

Page view na /lista-prioritaria

// Rota /lista-prioritaria — ao carregar a página (igual à raiz) window.dataLayer = window.dataLayer || []; window.dataLayer.push({ event: 'blackpass_page_view' });
